# codegen-edge-cases — Java client

Generated by `trix codegen` from the `codegen-edge-cases@0.0.1` protocol interface (TII v1beta0). Do not edit by hand — re-run `trix codegen` to refresh.

## Add the client to your application

This folder is a self-contained Maven project, `land.tx3.generated:codegen-edge-cases-client`, that depends on the runtime SDK `land.tx3:tx3-sdk`. Install it into your local repository and depend on it, or copy `src/main/java` into your own module:

```sh
mvn -B -ntp install
```

```xml
<dependency>
  <groupId>land.tx3.generated</groupId>
  <artifactId>codegen-edge-cases-client</artifactId>
  <version>0.0.0-SNAPSHOT</version>
</dependency>
```

The client needs Java 21. If you also need a local dev runtime, `trix devnet` exposes a TRP endpoint at `http://localhost:8164`.

## Use the client

```java
import land.tx3.generated.codegenEdgeCases.CodegenEdgeCasesClient;
import land.tx3.sdk.ClientOptions;

var client = new CodegenEdgeCasesClient(
    ClientOptions.forEndpoint(java.net.URI.create("http://localhost:8164")));
```

Each `tx` declared by the protocol becomes a typed method on the client taking a `record` of its parameters and returning the SDK's `TxBuilder`; drive it through `resolve → sign → submit → waitForConfirmed`. Each declared party has a `with<Party>` binder, and the protocol's custom types are nested `record`s and sealed interfaces of the client class. The client embeds everything it needs at runtime; the `.tii` file is not required. See the [Tx3 consuming guide](https://docs.txpipe.io/tx3/consuming/quick-start) for the full walkthrough.
