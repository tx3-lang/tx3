## Add the package to your application

This folder is a self-contained SwiftPM package exposing the `UnknownClient` library. From your consuming package's `Package.swift`:

```swift
dependencies: [
    .package(name: "UnknownClient", path: "path/to/this/folder"),
    .package(url: "https://github.com/tx3-lang/swift-sdk.git", from: "0.15.0"),
],
targets: [
    .executableTarget(
        name: "MyApp",
        dependencies: [
            .product(name: "UnknownClient", package: "UnknownClient"),
            .product(name: "Tx3SDK", package: "swift-sdk"),
        ]
    ),
]
```

The generated package already depends on the Tx3 Swift SDK; declaring `Tx3SDK` in your own target as well is what lets your application name SDK types such as `ClientOptions`, `Party` and `TxBuilder`. The package targets macOS 14 and iOS 18 or newer with Swift 6.1.

If you need a local dev runtime, `trix devnet` exposes a TRP endpoint at `http://localhost:8164`.

## Use the client

```swift
import Foundation
import Tx3SDK
import UnknownClient

let client = UnknownClient(
    options: ClientOptions(endpoint: URL(string: "http://localhost:8164")!),
    profile: .local
)
```

Each declared party becomes a typed `with…` setter taking a `Party`. See the [Tx3 consuming guide](https://docs.txpipe.io/tx3/consuming/quick-start) for the full walkthrough.
